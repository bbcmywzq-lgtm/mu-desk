# Vibecoding 作品方向地图（2026-08-22）

前两轮把范围误收窄到了“桌面工具”和“桌面特效”。这份地图改用作品形态分类：vibecoding 可以快速做出的不只是工具，也可以是世界、玩具、乐器、展览、故事、模拟实验、社交空间和现实接口。

## 1. 一条规则长成的玩具宇宙

先定义很少的规则，让复杂现象自己出现。用户不是完成任务，而是在观察、破坏、培育和分享结果。

- [Sandspiel](https://github.com/MaxBittker/sandspiel)：沙、水、火、植物等像素元素通过细胞自动机互动，既是游戏也是创作画布。
- 可做方向：生态瓶、蚂蚁社会、病毒扩散、浮岛气候、炼金反应、城市交通、语言演化。
- 适合 vibecoding 的原因：规则、渲染和交互可以逐层增加；没有内容资产也能成立。

## 2. 可漫游的小世界

不追求完整 RPG，先做一个具有天气、昼夜、地形和声音的地方，让人在里面走十分钟就有感受。

- [World of Light](https://github.com/teuzowebdeveloper9/world-light)：Claude Code 辅助构建的无限程序化 3D 冥想世界。
- [Veilspire](https://github.com/Lunaneco/veilspire)：浏览器中的程序化魔法世界，模型、声音和特效大量由代码生成。
- [Aetheria](https://github.com/mositron/Aetheria)：作者称其为集中冲刺完成的程序化浏览器 MMORPG，包含生态、宠物、飞行、住房和多人。
- 可做方向：雨夜车站、无尽图书馆、漂浮岛、深夜便利店、梦中博物馆、一座每天变化的城。

## 3. AI 角色生活的世界

把 AI 从聊天框里拿出来，让角色有位置、物品、关系、目标、记忆和时间表；语言模型只扮演角色，代码负责世界规则。

- [Aikami](https://github.com/BearlySleeping/aikami)：2D 空间 RPG，程序生成 NPC，AI Game Master 按真实属性和检定裁决。
- [ClawCity](https://github.com/marcel-heinz/clawcity.app)：AI Agent 自己探索、采集、交易、占地并参加周期比赛，人类是教练。
- [Loreweaver](https://github.com/1A7432/loreweaver)：AI 讲故事，代码负责骰子、伤害、理智和线索公平性。
- 可做方向：AI 酒馆、侦探公寓、妖怪旅店、宇宙货运站、虚拟剧组、会自行演化的邻里。

## 4. 生成式乐器与视听作品

产品不是“播放音乐”，而是让人通过鼠标、手势、文字、摄像头或数据共同演奏画面和声音。

- [Geno-1](https://github.com/tre-systems/geno-1)：三路生成音乐、空间音频和 WebGPU 波场共同变化。
- [GestureSynth](https://github.com/amerob/GestureSynth)：用双手控制旋律、鼓机、音量与 3D 波形。
- [ChromaSound](https://github.com/ling775/ChromaSound)：把手势同时映射成绘画、粒子和音乐。
- 可做方向：敲字作曲、照片变和弦、天气合成器、鼠标轨迹音乐、文件夹声景、情绪调色盘。

## 5. 世界生成器与创作者玩具

不是替用户产出一个答案，而是给他一套能不断随机、编辑、保存、衍生和分享的造物系统。

- [Fantasy Map Generator](https://github.com/Azgaar/Fantasy-Map-Generator)：程序生成并可深度编辑地形、国家、城市、道路、文化与历史。
- 可做方向：房间平面图、虚构城市、怪物谱系、服装纸娃娃、卡牌宇宙、菜谱生物、梦境地图、虚构公司史。
- 一个好生成器应保留“编辑与变异”，而不是只放一个生成按钮。

## 6. 可交互文章与思想实验

用滑杆、角色和模拟代替长篇解释，让用户亲手改变假设并看结果。

- [The Evolution of Trust](https://github.com/ncase/trust)：用小游戏解释囚徒困境、信任、宽恕与社会规则。
- [LOOPY](https://github.com/ncase/loopy)：让人自己画因果节点和反馈回路，再运行它。
- 可做方向：拖延为何发生、社交媒体回音室、复利、供应链、谣言传播、城市房价、团队沟通、密码安全。
- 这类作品非常适合短周期：一个明确观点、一套模型、一个连续体验即可发布。

## 7. 个人数据做成展览

不是仪表盘，而是把个人生活资料转译为可以漫游、回看和讲述的作品。

- [Life Calendar](https://github.com/Destaq/life-calendar)：把一生显示成日、周、月、年方格，并在其中写事件和目标。
- 可做方向：照片星系、音乐年度地形、聊天关系河流、代码提交城市、走过的地点拼成岛屿、桌面文件考古层。
- 数据可以全部本地导入；重点是形成可保存的“个人展品”，而不是指标统计。

## 8. 摄像头、声音和身体成为控制器

让普通电脑突然拥有新的输入方式，而不是只接受鼠标键盘。

- [GestureSynth](https://github.com/amerob/GestureSynth)：MediaPipe + Tone.js + Three.js，把双手变成乐器。
- [Blue Plaques AR](https://github.com/BabatundeOnabajo/Blue-Plaques-of-London-In-Augmented-Reality-AR-Vibe-Coded)：用手机识别现实中的历史牌匾并进入问答游戏。
- 可做方向：眨眼节奏游戏、姿势施法、摄像头影子剧、环境声音养宠物、房间寻宝、现实物体图鉴。

## 9. 小型经营、生态与社会模拟

经营游戏不一定需要大量美术；数字、事件、地图和角色关系就能产生故事。

- [Business Tycoon](https://github.com/TeamDay-AI/business-tycoon)：纯前端、无构建步骤的 AI 创业公司经营游戏，包含办公室、员工情绪、项目、科技树、经济和随机事件。
- 可做方向：一家午夜电台、怪兽诊所、时间旅行社、太空废品站、地下报社、炼金小店、AI 模型训练场。
- 适合做成每局 20–40 分钟的轻量模拟，而不是无限膨胀的商业游戏。

## 10. 共享的小空间

不做完整社交平台，只做一间屋、一块地、一面墙，让少量人留下痕迹或共同完成一件事。

- [PigeonWorld](https://github.com/PeerPigeon/PigeonWorld)：Three.js + WebRTC 的程序化 P2P 小世界。
- [DeskRPG](https://github.com/dandacompany/deskrpg)：像素办公室里有人类和 AI NPC 走动、交谈、开会和交付任务。
- 可做方向：朋友共享水族箱、异步涂鸦墙、两人共同养岛、匿名漂流电台、协作拼图、访客留下一个房间物件。

## 11. Agent 作为玩家、演员或居民

Agent 不只是帮人做事，也可以参加比赛、扮演角色、经营资产或共同创作。

- [ClawCity](https://github.com/marcel-heinz/clawcity.app)：Agent 是 MMO 玩家，人类制定策略。
- [Agent Arcade](https://github.com/DanWahlin/agent-arcade)：把等待 Agent 工作的时间变成透明桌面街机。
- 可做方向：多个模型辩论后建城、Agent 足球经理、AI 即兴剧团、模型拍卖会、自动侦探赛、不同模型共同写一座博物馆。

## 12. 互动叙事与可持续世界

不是“让 AI 续写”，而是用代码维护地点、物品、角色状态和因果，AI 负责局部表演。

- [TaleWeave AI](https://github.com/ssube/taleweave-ai)：世界生成、多人文字冒险、AI NPC 与 Discord/Web 入口。
- [Horde Studio](https://github.com/ddkhan24/hordestudio)：角色、世界、关系、日程、天气、市场和多条时间线持续演化。
- 可做方向：七天悬疑案、会衰老的家族史、航海日志、宿舍群像、跨时代书信、只有夜晚开放的城市。

## 13. 浏览器里的专用创作室

把一个专业创作流程压缩成一个极小工作室，让用户看得见过程并反复改。

- [frontend-slides](https://github.com/zarazhangrui/frontend-slides)：让编码 Agent 直接制作网页幻灯片。
- [html-anything](https://github.com/nexu-io/html-anything)：把杂志、海报、演示、社交图片和数据报告统一成可导出的 HTML 创作表面。
- 可做方向：漫画分镜室、MV 情绪板、播客片头机、虚构杂志编辑部、卡牌排版室、动态海报实验室。

## 14. 现实世界的窄场景产品

Vibecoding 也适合把非常小众的现实工作流直接产品化，用户可能只有一个人，但价值很具体。

- [MikLink](https://github.com/ShitWRKS/MikLink)：把特定路由器变成网线检测探针并生成报告。
- [Blue Plaques AR](https://github.com/BabatundeOnabajo/Blue-Plaques-of-London-In-Augmented-Reality-AR-Vibe-Coded)：只服务伦敦历史牌匾这一种现实场景。
- 可做方向：个人藏品鉴定、阳台植物巡检、房间声学测量、旧物档案、家庭仪表盘、自制硬件控制台。

## 15. 系统与媒介实验

作品本身可以是对“电脑还能是什么”的实验，不一定马上有用户价值。

- [VibeOS](https://github.com/kaansenol5/VibeOS)：面向 AArch64、完全以 vibecoding 方式构建的操作系统实验。
- [OpenRoom](https://github.com/MiniMax-AI/OpenRoom)：浏览器里的桌面环境，Agent 可以通过自然语言操作其中的应用。
- 可做方向：一台虚构的 1997 年电脑、只用声音操作的桌面、文件即生物的操作系统、梦境终端、由 Agent 每天重组的界面。

## 更适合当前集合的五条主线

如果继续围绕“一个集合里装很多小作品”，最值得发展的不是 15 张工具卡，而是五个作品频道：

1. **小世界**：每次打开进入一个可漫游、会变化的微型地点。
2. **实验室**：沙盒、生态、社会规则和可交互解释。
3. **造物室**：地图、角色、卡牌、声音、海报和故事生成器。
4. **剧场**：AI 角色、Agent 比赛、互动叙事和持续世界。
5. **个人博物馆**：把照片、音乐、地点、文件和时间变成私人展览。

它们可以共享同一壳、保存系统、导出系统和素材库，但每个作品不必被解释成“工具”。

## 第一批最值得试作的作品

- **声音植物园**：鼠标种植物，系统音乐决定其生长、颜色和风向；结合生成式音乐、生态模拟和个人展览。
- **一口世界**：一句描述生成一座只能漫游十分钟的小世界，退出时保存一张旅行明信片。
- **AI 酒馆**：固定十个有日程、关系和秘密的角色；每天发生一件由代码规则推动的事件。
- **人生星图**：导入照片、音乐或日记，将几年生活生成可漫游星系，而非统计图。
- **因果游乐场**：用户画出“睡眠—压力—咖啡—效率”等节点，系统运行反馈回路并生成不同结局。
- **代理斗兽场**：给多个 Agent 相同资源和不同性格，让它们经营、谈判或破案，人类只设规则并旁观。

这些方向的共同点是：首版可以很小，但体验完整；不依赖大量后台集成；每次迭代都能增加规则、内容和风格，而不是只增加设置项。
