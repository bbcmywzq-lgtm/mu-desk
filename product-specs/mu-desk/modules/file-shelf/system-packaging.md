# 临时货架系统包装

Parent SKU: `MU-DESK`  
Module ID: `file-shelf`  
Gate: System Packaging — accepted 2026-08-22

## Identity and entry

- User-facing product identity: MU Desk.
- Module display name: 临时货架.
- Executable: no module executable；货架窗口、拖放和持久化均在 MU Desk 进程中运行。
- Taskbar/application identity: MU Desk；边缘货架不创建独立任务栏按钮。
- Entry points:
  - MU Desk 首页模块卡片：开关、`显示货架` / `收起货架`。
  - MU Desk 统一托盘的一项：`临时货架…`，用于显示/收起现有货架。
  - 屏幕边缘折叠标签：仅在模块启用且 MU Desk 未暂停全部工具时存在。
- 不提供独立快捷方式、全局快捷键、兼容启动器或第二个普通用户入口。

## Startup, process, and background behavior

- 不建立模块专属开机启动项；是否随登录可用完全继承 MU Desk 的开机启动设置。
- 模块默认启用。升级后首次启动也显示折叠标签，但不自动展开、不抢焦点、不弹通知。
- 关闭模块时立即移除边缘窗口并停止拖放监听；已保存的货架元数据保留。
- `暂停全部工具` 隐藏边缘窗口并停止接受拖放；恢复后按先前显示状态回到折叠标签。
- 同一时间只存在一个货架窗口；重复入口激活或收起现有窗口，不创建副本。
- 模块不扫描磁盘、不监控目录、不读取剪贴板，也不在空闲时轮询路径可用性。路径只在显示条目或尝试拖出时检查。

## Settings ownership

所有设置属于 MU Desk 共享设置模型和统一设置页，不建立模块设置文件或独立设置窗口。

Settings:

- Enabled: default `true`.
- Dock side: `right` or `left`，default `right`.
- Dock screen: 保存 Windows 显示器设备标识；设备不存在时回退主屏幕。
- Vertical position: 保存为当前工作区高度的 0–1 相对比例，default `0.50`；显示器或 DPI 变化后夹在安全范围内。
- Start presentation: always collapsed；应用启动时永不自动展开完整货架。
- Reduced motion: 跟随 Windows，不提供私有重复开关。

不保存最后一次外部目标应用、拖出目的地、窗口标题、鼠标轨迹或拖放失败应用名称。

## Local data ownership

Default root:

`%LocalAppData%\MU Desk\file-shelf`

Structure:

```text
file-shelf/
├── shelf.json
├── shelf.json.bak
└── logs/
```

- `shelf.json` 只包含 schema version、批次 ID、项目绝对路径、显示名称、文件/文件夹类型、放入时间、顺序和固定状态。
- 写入采用临时文件加原子替换；替换前保留一个最近成功版本为 `shelf.json.bak`。
- `shelf.json` 和备份都属于用户本地元数据，不进入应用安装目录，也不随升级覆盖。
- 不复制源文件，不建立缓存副本，不生成内容缩略图，不保存文件哈希、正文、媒体元数据或文件夹清单。
- Windows 文件类型图标通过系统 Shell 图标接口按路径/扩展名按需获取；图标只用于显示，不读取文件正文，也不持久化为内容缓存。
- 最大首版容量为 200 个路径条目；达到上限时拒绝新增并显示真实原因，不自动淘汰旧项目。

## Privacy boundary

- 本地绝对路径可能包含用户名、客户名或项目名，按私密数据处理。
- 模块无网络请求、遥测、云同步或 Codex/AI 发送能力。
- 日志不得记录完整路径、文件名或文件夹名；仅记录条目数量、操作阶段、错误类型和不可逆散列之外的随机批次 ID。
- 错误界面可以向当前用户显示相关路径，以便恢复，但不得将路径复制到剪贴板或诊断日志。
- 不访问文件权限之外的数据，不请求管理员权限，不绕过 Windows 访问控制。

## Drag-and-drop ownership

- 拖入只接受 Windows `FileDrop` 中的本地文件系统路径；拒绝浏览器虚拟下载、纯文本 URL、邮件附件虚拟对象和未落盘的云占位数据。
- Drop 完成的成功条件是路径格式有效、条目未超过上限且新元数据已经可靠写入磁盘。
- 拖出使用 Windows 标准文件拖放数据；目标应用决定复制、移动、链接、打开或拒绝，MU Desk 不强制效果。
- 只有 Windows 拖放返回非 `None` 结果时，未固定条目才从货架元数据移除；固定条目永不因拖出自动移除。
- 拖出后的元数据移除失败时，条目保留并报告失败；不得假装货架已经清理。
- 模块永不根据目标拖放效果去删除、移动或重命名源路径。

## Tray, focus, and notifications

MU Desk 保持唯一托盘图标。在现有模块命令中加入 `临时货架…`：

- 模块启用且折叠：显示展开货架并把键盘焦点放到第一项或空状态。
- 模块启用且展开：收起到边缘标签。
- 模块关闭：显示 MU Desk 首页并定位到临时货架卡片，不私自启用。

- 拖入、拖出、固定和清空都不发送系统通知或托盘气泡；反馈留在货架内。
- 边缘窗口不抢占前台焦点；只有用户点击或从托盘/首页主动打开时才进入键盘交互。
- 展开后失去焦点不会立刻关闭；短暂离开用于切换目标窗口是核心流程。用户明确收起或完成拖出后按规则收起。

## Removal, undo, and reset

- `移除`、`清空未固定项` 和成功拖出后的自动清理都只修改货架元数据，不删除磁盘源文件。
- `清空未固定项` 必须先显示范围确认；固定项明确不在清空范围内。
- 当前 MU Desk 会话内保留一次最近移除快照；撤销只恢复路径条目，不恢复或改动源文件。
- 退出 MU Desk 后撤销历史不保留；`shelf.json` 只保存当前可见货架状态。
- 重置模块设置恢复启用、右侧、主屏幕和中部位置，但不清空条目。
- “清空货架数据”是单独的显式操作，确认文案必须写明“不会删除原文件”。
- 卸载或普通升级不主动删除 `%LocalAppData%\MU Desk\file-shelf`；若安装器提供删除用户数据选项，必须沿用 MU Desk 统一确认流程。

## Recovery and errors

- 主文件解析或校验失败时先尝试只读加载 `.bak`；恢复成功后显示 `已从备份恢复货架`，并在下一次明确修改时重写主文件。
- 主文件与备份均失败时保留损坏文件，启动一个空的内存视图并显示可操作错误；不得静默覆盖。
- 原路径不存在、网络盘离线、移动硬盘未连接或权限不足时标记 `不可用`，不自动移除。
- 网络盘和可移动盘重新可用后，在用户展开货架或尝试拖出时重新检查并恢复可用状态。
- 元数据保存失败时新增、固定、移除或清空操作必须回滚到最后可靠状态。
- 诊断提供 `打开数据位置`，但不提供上传日志或一键发送路径清单。

## About, versioning, and distribution

- 无独立 About、作者署名、发布者、版本、隐私页、安装器、更新器或发布渠道。
- 版本和发布说明继承 MU Desk semver；功能只随 MU Desk Windows x64 包发布。
- 数据格式增加 `schema_version`；不兼容升级必须先保留可恢复备份，不能用清空作为迁移方案。
- 模块不新增第三方常驻服务、Shell 扩展、驱动、浏览器组件或管理员权限要求。

## System Packaging acceptance

- 一个 MU Desk 进程、托盘、启动项、设置所有者、版本和安装包。
- 模块默认启用但只显示折叠标签；不抢焦点、不自动展开、不弹通知。
- 统一首页和托盘入口，无独立快捷方式、全局快捷键或任务栏身份。
- 路径元数据只保存在 `%LocalAppData%\MU Desk\file-shelf`，原子写入并保留一个恢复备份。
- 只接受已落盘本地路径；不扫描目录、不读剪贴板、不读取内容、不缓存文件、不联网。
- Windows 目标应用决定拖放效果；MU Desk 永不复制、移动、重命名或删除源文件。
- 移除、清空、成功拖出和重置都只处理货架元数据；普通升级和卸载不主动删除货架数据。
- 完整路径不进入日志；主文件损坏、保存失败、路径离线和权限问题均真实可见并可恢复。
