# 临时货架模块定义

Parent SKU: `MU-DESK`  
Module ID: `file-shelf`  
Gate: Product Definition — accepted 2026-08-22

## Product role

临时货架是 MU Desk 的内部常驻辅助模块。它在用户跨窗口搬运本地文件或文件夹时提供一个靠屏幕边缘、可随时拖入和拖出的中转位置。它不是文件管理器，不接管原文件，也不建立独立产品、进程、托盘、启动项、版本或安装包。

## User and dominant task

- User: 经常要在资源管理器、浏览器、聊天工具、编辑器或设计软件之间搬运少量文件的个人 Windows 用户。
- Dominant task: 先把当前选中的文件或文件夹“搁一下”，切换到目标窗口后再把它们拖出来。
- Success: 用户不必并排摆放两个窗口，也不必依赖剪贴板历史；一次拖入、一次拖出即可完成中转。

## Entry model

- Primary entry: MU Desk 首页模块卡片，用于显示或收起货架。
- Ambient entry: 屏幕边缘保留一个低干扰的折叠标签；外部文件拖到标签上时展开货架并接受放入。
- Tray entry: 后续在 System Packaging gate 决定是否加入统一托盘菜单；不得创建独立托盘图标。
- No standalone executable, startup item, updater, installer, or second product identity.

## Core workflow

1. 用户从任意支持 Windows 文件拖放的应用拖起一个或多个本地文件或文件夹。
2. 指针进入屏幕边缘的货架标签后，货架展开并显示可放入状态。
3. 用户放下项目；同一次拖入的项目形成一组，并显示名称、类型、数量和可用状态。
4. 用户切换到目标窗口，重新从货架拖出单项或整组。
5. 当 Windows 拖放返回成功结果时，未固定项目从货架移除；固定项目继续保留。
6. 用户也可以手动移除一项、清空未固定项，或撤销本次会话内最近一次移除。

## Data contract

- 只保存本地绝对路径、显示名称、项目类型、放入时间、分组标识、顺序和固定状态。
- 不复制、移动、重命名、删除、上传或修改原始文件和文件夹。
- 不读取文件正文、媒体内容、压缩包内容或文件夹内部清单。
- 元数据保存在 `%LocalAppData%\MU Desk\file-shelf\shelf.json`，并随 MU Desk 重启恢复。
- 原路径失效时保留条目并明确显示“不可用”；不得伪装成仍可拖出。

## Visible content and actions

- 折叠边缘标签：显示当前项目数量和展开入口。
- 展开货架：按放入批次分组，显示文件/文件夹系统图标、名称、数量、固定状态和不可用状态。
- Actions: 拖入、拖出、固定/取消固定、移除、清空未固定项、撤销最近一次移除、收起。
- 首页卡片：显示模块开关、当前货架数量和“显示货架”操作。

## States

- Disabled: 边缘标签不出现，已有元数据保留。
- Empty: 货架展开但没有项目，说明可从任意窗口拖入文件或文件夹。
- Drag over valid / invalid: 明确区分可接受的本地路径和不支持的数据格式。
- Populated: 条目按批次和放入时间显示。
- Dragging out: 保持条目，直到 Windows 返回成功拖放结果。
- Missing: 原路径不存在或暂时不可访问。
- Persist error: 元数据保存失败可见，当前内存中的项目不伪装成已持久化。
- Undo available / expired: 只保证当前 MU Desk 会话内最近一次移除可撤销。

## Explicit exclusions for the first version

- 复制、移动、删除、重命名或自动整理原文件。
- 文件正文索引、全文搜索、缩略图内容预览、媒体播放或压缩包浏览。
- 剪贴板历史、下载管理、收藏夹、最近文件聚合或文件启动器。
- 自动过期、定时清理、容量配额和后台目录监控。
- 云同步、账号、分享、协作或网络上传。
- Windows 资源管理器 Shell 扩展、浏览器扩展或对第三方应用注入代码。
- 独立窗口常驻进程、托盘、开机启动、品牌、版本或安装包。

## Preservation and safety requirements

- 不改变现有五个首页工具的行为、设置或数据。
- MU Desk 继续拥有唯一普通用户入口、托盘、开机启动、设置、版本和发布包。
- 任何“移除”“清空”只删除货架元数据；绝不删除磁盘上的源文件或文件夹。
- 拖出失败或被目标应用拒绝时，货架条目必须保留。
- 文件路径属于本机隐私数据；首版不得发送到网络或写入日志正文。

## Product Definition acceptance conditions

Gate A 只有在用户明确接受以下完整定义后才通过：

- 内部模块身份和面向用户名称“临时货架”；
- 屏幕边缘折叠标签、拖入暂存、切换窗口后拖出的核心交互；
- 同批分组、固定保留、成功拖出后自动移除未固定项；
- 只保存路径元数据并跨 MU Desk 重启恢复；
- 原文件零复制、零移动、零删除、零上传、零内容读取；
- 首版不做剪贴板历史、内容搜索/预览、自动过期、云同步或 Shell 扩展。

Gate evidence: 2026-08-22 用户明确回复“接受 Gate A”。
