# 临时货架视觉系统

Parent SKU: `MU-DESK`  
Module ID: `file-shelf`  
Gate: Visual System — accepted 2026-08-22

## Inheritance

- Standard: `MU Product Standard 1.0.1`.
- MU Desk 首页与设置入口：`light-outlined`。
- 屏幕边缘标签与展开货架：`dark-translucent`，保证覆盖在任意应用上仍清楚，但不伪装成系统窗口。
- Density: 货架使用 compact；首页卡片使用现有 normal 密度。
- Token overrides: none.
- Typography: Segoe UI Variable，中文回退 Microsoft YaHei UI。
- Copy: 简短、功能性；“搁一下”只作为动作短句，不成为独立品牌。

## Visual principle

货架应该像一个随手可用的临时落点，而不是第二个资源管理器。默认状态只留下低干扰的边缘标签；用户拖入或主动展开时才出现完整内容。视觉重点是“这些路径还在不在、属于哪一批、拖出后会不会留下”，不展示文件正文或内容缩略图。

## Surface map

### 1. MU Desk module card

- 继承现有首页模块卡片的暖白表面、深色描边、圆角和间距。
- Name: `临时货架`。
- Descriptor: `文件先搁一下，换个窗口再拖走`。
- Primary action: `显示货架`；货架已显示时改为 `收起货架`。
- 卡片展示真实项目数量，例如 `3 项 · 1 项已固定`；关闭模块时显示 `已关闭`。
- 提供与四向轮盘、桌面整理相同视觉语言的模块开关，但不得用开关替代“显示货架”动作。

### 2. Collapsed edge tab

- 首版默认停靠主屏幕右侧中部；后续包装合同决定是否保存左右侧选择。
- 可见尺寸约 36 × 92 px；触控/点击目标不小于 36 × 44 px。
- 使用深炭灰半透明表面、1 px 浅色内描边和克制阴影；与桌面背景保持稳定对比。
- 垂直排列模块图标、真实项目数和展开箭头；空货架显示 `0`，不显示假通知点。
- 普通空闲状态不闪烁、不脉冲、不沿屏幕漂移。
- 指针悬停或键盘聚焦时只提高表面亮度并显露提示 `临时货架`。

### 3. Drag approach and drop target

- 外部文件拖到边缘标签时，货架在 120–160 ms 内沿屏幕边缘展开；Windows 减少动态效果开启时直接出现。
- 整个内容面板成为明确的放置目标，边框转为暮光紫，并显示 `放到这里 · 3 项`。
- 不支持的数据格式使用中性禁止形状和文字 `这里只接收本地文件或文件夹`，不能只靠红色。
- 拖入反馈不得遮住指针附近的文件拖动图标或伪装成已经成功保存。
- 只有 Drop 成功并完成元数据写入后，才显示新增条目和短暂状态 `已搁下 3 项`。

### 4. Expanded shelf

- 贴右侧时面板从右向左展开；首版宽度 320 px，高度随内容变化并限制在工作区的 360–640 px 范围内。
- 面板保持在任务栏工作区内，不覆盖系统托盘；200% 缩放时按有效像素重排，不缩成难以点击的版本。
- Header: 模块图标、`临时货架`、项目总数、收起按钮。
- Body: 按拖入批次排列；每批显示相对时间和项目数量，不要求用户命名。
- Footer: 次要操作 `清空未固定项`；最近一次移除后出现限时可用的 `撤销`，不得将清空做成主操作。
- 空状态直接显示 `把文件或文件夹拖到这里`，不使用插画占据空间。

### 5. Item and group construction

- 每项使用 44–52 px 高的紧凑行：运行时获取的 Windows 文件类型图标、单行名称、简短类型或路径状态、固定按钮和移除按钮。
- 文件名优先；路径只在 tooltip/辅助信息中显示，避免面板成为路径墙。
- 文件夹与文件通过系统图标加文字类型共同区分，不使用内容缩略图。
- 同一批多项使用一条共享组边界；整组拖出入口可见为 `拖出整组`，单项本身也可拖。
- 固定状态使用填充图钉加文字提示，不只改变颜色。
- 原路径失效时降低内容对比度、显示断链图标和 `不可用`；保留移除操作，禁止开始虚假的拖出。

## Drag-out feedback

- 开始拖出时，原行保留位置并转为轮廓占位，直到 Windows 返回结果。
- 拖放成功：未固定项以 100–140 ms 淡出并从列表移除；固定项恢复正常。
- 拖放取消或目标拒绝：占位立即恢复，并显示一次 `没有移出，仍在货架上`。
- 不使用“已复制”“已移动”等措辞，因为货架不决定目标应用如何处理拖放。

## Color, shape, and type

- `light-outlined` 继承 canvas `#EEF0F5`、surface `#FAFAFC`、ink `#25252A`、muted ink `#73737D`、violet `#8055D9`、pale violet `#E9DEFF`。
- `dark-translucent` 以 `#202127` 为主体（约 92–96% 不透明度），正文使用接近白色，次要文字保持至少 WCAG AA 对比。
- 暮光紫只表达当前拖放目标、选中/固定状态和主要操作；危险色只用于清空确认，不用于普通移除悬停。
- 面板圆角 14 px，条目圆角 9–10 px，描边 1–1.5 px。
- 只允许受控阴影和轻微背景材质；无霓虹光晕、毛玻璃文字、渐变描边或装饰性颗粒。

## Module icon plan

Metaphor: 一个正面可见的浅色小货架，三张不同高度的文件页暂放在槽内，其中一张用暮光紫表示当前落点。

- Family language: 扁平圆润、深炭描边、暖白主体、单一紫色状态部件。
- 轮廓要明显区别于“文件夹”“下载箭头”“收件箱”和“回收站”。
- 16–20 px 版本简化为一条货架横板、两张文件页和一个紫色落点，不保留细小折角。
- Production targets after Gate B: 16, 20, 24, 32, 64, 128, 256 px。
- Fallback: code-native shelf with two file tabs。
- Current state: integrated；正式资产位于 `artifacts/file-shelf-icons-v1`，16–256 px 已完成 QA 并接入 MU Desk。

## Illustration decision

本模块不使用角色或编辑插图。贴边空间有限，文件系统图标和真实条目本身已经提供足够视觉信息；空状态由代码原生货架图标和直接说明构成。

## Motion boundary

- 展开/收起：120–160 ms 水平位移加透明度，不能使用弹簧回弹。
- 新增/移除：100–140 ms 透明度和 2 px 以内位置反馈。
- 拖动跟手，不添加缓动延迟；拖放状态是功能反馈，不是装饰动画。
- 无自动循环、呼吸、闪烁或注意力争夺动画。
- 遵循 Windows 减少动态效果设置，必要时直接切换状态。

## Accessibility and platform fit

- 所有图标按钮具有 tooltip、可访问名称和可见焦点；固定、不可用、拖入有效性均有文字或形状提示。
- Enter/Space 激活按钮；Escape 收起货架或取消当前面板操作，但不得清空内容。
- 面板支持键盘逐项浏览；上下键移动条目，Tab 进入固定、移除和底部操作。
- 最小常用点击区域 32 × 32 px；边缘主入口不小于 36 × 44 px。
- 支持多显示器每屏 DPI；货架必须完整位于选定屏幕工作区，不能跨 DPI 边界模糊拉伸。
- 在高对比度模式中降级为实色背景和系统边框，功能与状态不依赖透明材质。

## Visual acceptance

- 空闲时只留下一个低干扰边缘标签；拖入或主动展开时，完整货架才出现。
- 有效拖入、无效拖入、元数据保存失败、路径不可用、拖出成功和拖出失败彼此可辨。
- 用户能一眼看出项目数量、同批关系、固定状态和不可用状态。
- 面板不会被误认为资源管理器，也不会暗示它复制、移动或删除了源文件。
- 贴边层在明亮、深色和复杂桌面背景上均可读，并在 200% 缩放和多显示器环境中保持完整。
- 模块视觉属于 MU Desk，不引入独立品牌、角色插图或第二套配色。
