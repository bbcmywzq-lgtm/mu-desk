# Mujun Cue 产品定义

Parent SKU: `MU-DESK`  
Module ID: `mujun-cue`  
Gate: Product Definition — corrected, pending review

## Identity

- 子软件名称：`Mujun Cue`。
- 总包与唯一系统入口：`MU Desk`。
- 功能描述：`屏幕演示与实时讲解工具`。
- 模块窗口标题：`Mujun Cue · MU Desk`。
- `Mujun Cue` 是明确批准的内部子软件名称，不是独立 Windows 产品身份。

## Audience and promise

- 第一用户：软件所有者本人。
- 首要场景：在线会议、直播和课堂中的实时屏幕讲解。
- 核心承诺：用低延迟、可随时恢复的屏幕指示、聚焦与标注能力，把屏幕内容讲清楚。
- 第一版合格条件：连续使用 30 分钟不出错；瞬时聚焦响应迅速；松键、退出或异常时屏幕必定复原；覆盖层不意外吞掉普通输入。

## Module topology

Mujun Cue 在 MU Desk 中作为一个模块卡片和一组按需覆盖层存在。它继承 MU Desk 的唯一进程入口、托盘、开机启动、统一暂停、设置持久化、错误出口、版本与发布包。

Mujun Cue 可拥有：

- 一张 MU Desk 首页模块卡片；
- 一个模块图标；
- 一个统一设置入口；
- 一个可横向/纵向切换并吸附屏幕边缘的临时工具栏；
- 全屏覆盖层、局部镜片、标注层、截图选择层、画板和计时器窗口；
- 可分配给快捷轮盘的动作。

Mujun Cue 不拥有：

- 独立 EXE、普通用户启动入口或任务栏产品身份；
- 独立托盘、开机启动项、安装包、更新通道或 About 页面；
- 独立版本号、发布节奏或数据根目录。

## Phase 1 scope

### 1. Pointer guidance

- 激光点与可配置渐隐拖尾；
- 光标高亮圆环；
- 点击扩散反馈；
- 颜色、尺寸、透明度和持续时间设置；
- 各效果可任意组合并保存个人预设；
- 临时效果使用按住交互，持续效果使用切换交互。

### 2. Spotlight

- 圆形、圆角矩形和自由框选聚光区域；
- 调整半径、形状、暗部透明度；
- 跟随鼠标或固定区域；
- 支持按住临时显示和持续切换；
- 可与局部放大镜及指针效果组合。

### 3. Local magnifier

- 圆形与圆角矩形镜片；
- 实时跟随鼠标；
- 可调倍率与镜片尺寸；
- 同时支持按住显示和切换显示；
- 普通桌面交互保持可用。

### 4. Focus Hold

- 按住触发键时，以鼠标所在位置为中心放大全屏；松开后恢复；
- 默认倍率 `2×`，范围 `1.25×–5×`，步长 `0.25×`；
- 按住期间滚轮调整倍率并记住最后值；
- 采用鼠标死区与平滑视野跟随，减少轻微抖动；
- 拉近与恢复动画默认约 `120 ms`，允许调整或关闭，并尊重 Windows 减少动态效果设置；
- 默认只影响鼠标所在显示器，可设置为处理全部显示器；
- 放大期间除触发键外，点击、滚动和键盘输入正常传递；
- 默认触发键为 `Caps Lock`：短按保持系统大小写切换，按住超过默认 `160 ms` 进入聚焦；阈值可调；
- 松键、退出、崩溃恢复和紧急复原必须回到 `1×`。

### 5. Live annotation

- 画笔、荧光笔、橡皮擦、直线、箭头、矩形、椭圆、文字和编号步骤；
- 支持撤销、重做、清空，以及选择、移动和删除单个对象；
- 支持按住临时标注和持续标注；
- 默认在实时桌面上标注，另提供主动冻结当前画面；
- 可配置标注自动渐隐。

### 6. Screenshot

- 框选区域、鼠标所在显示器、整个多屏桌面及指定窗口截图；
- 默认复制到剪贴板并自动保存；
- 默认保留标注，隐藏工具栏和鼠标辅助效果；截图前可改变保留项；
- 截图工具自身不得污染捕获结果。

## Phase 2 scope

### 7. Boards

- 白板、黑板和冻结当前屏幕；
- 复用 Phase 1 标注工具；
- 导出图片；
- 保存可继续编辑的本地项目；不默认保存每一次临时画板。

### 8. Timer

- 倒计时、正计时、当前时间和距离指定时刻；
- 可移动、置顶并调整显示样式；
- 视觉提醒和声音提醒分别可关闭；
- 暂停、继续、复位和结束操作。

## Shared interaction and safety

- MU Desk 是唯一托盘；Mujun Cue 入口位于首页、统一托盘和可选快捷轮盘动作中。
- 各全局快捷键必须先检测冲突；除 Focus Hold 外不强制预占单键。
- `Esc` 连按三次、`Ctrl+Alt+Esc` 和 MU Desk 托盘“全部复原”均可关闭所有 Cue 效果。
- MU Desk 的“暂停所有工具”必须停用 Cue 的全局触发和覆盖层；恢复后按保存状态重新待命。
- 同一效果重复触发时激活或关闭现有实例，不创建重复钩子或覆盖层。
- 软件完全离线、无遥测、无需管理员权限，不上传屏幕内容。
- 配置由 MU Desk 统一保存；Mujun Cue 不在程序目录创建第二套便携配置。

## Compatibility boundary

- 目标系统：MU Desk 当前支持的 Windows 10/11 x64。
- 第一版覆盖浏览器、Office、聊天/会议软件和普通全屏应用。
- 不承诺 DRM/受保护画面、独占全屏游戏、高权限窗口或反作弊环境。
- 第一版保证桌面/显示器捕获可以看到 Cue 覆盖效果；不保证第三方软件“仅捕获单个应用窗口”时能够合成外部覆盖层。
- 多显示器覆盖层必须按每屏 DPI 渲染，不把多个显示器拉伸成模糊画布。

## Visual inheritance

- 管理、设置和可编辑画板控制面使用 MU `light-outlined`。
- 屏幕覆盖层、工具栏、聚焦 HUD 与计时浮层使用 MU `dark-translucent`。
- 使用现有 MU Desk 字体、圆角、描边、紫色强调、状态色、动效时长和可访问性规则。
- 不为 Mujun Cue 建立第二套主题 token；模块图标和实际表面在 Visual System gate 单独定义。

## Explicit exclusions

- 云同步、账号、多人协作和远程控制；
- 自动上传截图、标注或屏幕内容；
- 视频录制、剪辑和直播推流；现有“动态拾取”模块继续负责短时动态捕获；
- 专业绘图图层、复杂笔刷、压感和图形识别；
- 第一阶段实现画板和计时器；
- 为 Mujun Cue 创建独立品牌包装或独立后台常驻程序。

## Product Definition acceptance conditions

Gate A 只有在用户明确接受以下完整定义后才通过：

- Mujun Cue 是 MU Desk 内具有独立名称的子软件，但系统包装身份仍属于 MU Desk；
- 个人使用和实时屏幕讲解是第一方向；
- Phase 1 与 Phase 2 的功能边界；
- Focus Hold 的 Caps Lock 双用途、全屏缩放、跟随、输入传递和恢复行为；
- 统一入口、离线隐私、兼容范围和明确排除项；
- 继承 MU Desk 视觉系统，具体图标与表面留到 Gate B。
