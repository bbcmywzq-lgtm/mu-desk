# Mujun Cue 视觉系统

Parent SKU: `MU-DESK`  
Module ID: `mujun-cue`  
Gate: Visual System — accepted 2026-09-05

## Inheritance

- Standard: MU Product Standard `1.0.1`.
- 首页卡片、设置、截图结果与画板控制：`light-outlined`。
- 聚光、放大镜、聚焦 HUD、标注工具栏与计时浮层：`dark-translucent`。
- 使用现有 `MuProductTheme.xaml` 的颜色、字体、圆角、描边、按钮、状态和焦点资源，不新增主题 token override。
- 普通反馈采用 120–180ms；实时跟随不得加入造成指针滞后的装饰缓动；尊重 Windows 减少动态效果。

## Surfaces

- 首页只增加一张同级模块卡片：标题 `Mujun Cue`，描述 `聚焦、放大并讲清屏幕内容`，主操作 `打开工具栏`，次操作 `设置`。
- 工具栏为顶部居中的紧凑深色半透明横条，统一线性图标、中文标签与紫色开启态，按指示、截图、系统操作分组。
- 启用后常驻顶部 72 × 12 DIP 深灰小刘海，只保留短细线，无文字、圆点、箭头和明显描边。动画期间固定 HWND 尺寸与工具布局，只动画裁剪区域和透明度；临界阻尼曲线保留反向时的位置/速度，420ms 内收敛，120Hz 动画时钟请求不代表实测显示帧率。工具本身不缩放，使用临时绘制缓存；收敛后才把 HWND 收回 72 × 12。尊重 Windows 减少动态效果。普通模式离开 1.6 秒后自动收起，从 Desk 打开保留 4 秒宽限。
- Focus Hold 不显示遮挡内容的大面板，只在倍率变化时短暂显示小型 `2.00×` HUD。
- 放大镜无彩色描边，边缘渐隐与桌面自然融合；工具栏开启态使用紫色。激光、点击、录制状态不只依赖颜色传达。
- 激光使用连续红色细光迹与微亮光芯，不使用离散圆点、硬白描边或大光球。尾迹按时间与弧长收束，最长约 220 DIP、消退约 340ms；停下只留小光点。窗口隐藏/停用时清空轨迹并解除绘制订阅。
- 标注模式复用主工具栏窗口，不叠加第二条工具栏；绘图中不自动收起，手动收起后刘海仍返回标注工具。拖动 Cue 品牌区域可吸附本屏上方/下方。
- 标注工具分为绘制、颜色/尺寸、编辑历史、画面/退出几组。形状、颜色、尺寸用就地深色菜单；文字显示字号，编号提示下一个序号；“更多”提供清空、复制图片和保存 PNG。
- 笔迹、荧光、整支箭头、形状、文字、编号共享按操作顺序的撤销/重做；橡皮点击删除完整对象，清空可撤销。文字完成后无输入框，双击可重编，Enter 提交，Shift+Enter 换行。Esc 优先取消草稿/文字编辑，再次 Esc 退出。
- 标注以进入时所在屏幕为画布。实时背景可切换到“已冻结”，冻结捕获前隐藏画布和工具栏，防止自捕获；复制/保存把干净背景与标注合成，不包含工具栏。“桌面”模式先解除冻结再穿透鼠标，点击“绘图”恢复。
- 退出标注隐藏画布、回到主工具栏；本次 Desk 运行期间保留对象及历史，再进入继续编辑。停用模块只释放窗口，再启用仍可继续；退出 Desk 才释放会话，不跨进程保存草稿。标注期间暂停聚焦、激光、聚光和放大镜，退出后按原设置恢复。

## Icon

- 方向：一个深色描边的屏幕框，内部由紫色聚焦角与白色指针组成；只保留一个“屏幕讲解”隐喻。
- 首次实现使用代码原生 DrawingImage，保证与首页现有 34px 光学主体一致。
- 后续若生产位图，目标为 16、20、24、32、64、128、256px；未批准前不生成装饰插图。

## Accepted basis

- 用户明确要求“风格选择我们的 desk 工具箱通用风格并接入其中，其他的你自己看着办”。
- 用户随后明确要求“直接开始开发”，接受该继承方向并授权落地。
- 用户于 2026-09-05 要求重做工具栏外观，收起后保留屏幕最上方的小刘海入口。
- 同日用户反馈激光外观不佳，重做为上述连续细光迹。`Cue.Diagnostics --laser` 验证 30/60/144/240 Hz 模拟输入下无断点、尾迹过期、光标跳跃重置、采样有界以及窗口显示/隐藏/停止的绘制生命周期；这些是输入采样测试，不代表实测屏幕帧率。浅/深背景预览：`artifacts/cue-laser-preview.png`。
- 用户审阅标注/刘海统一改造方案后明确要求“改吧”。`Cue.Diagnostics --annotation` 覆盖混合历史、整对象橡皮、清空恢复、文字编辑、菜单选择、模式保持、冻结干净背景像素、PNG 合成、原生穿透标志和退出/重入；`--toolbar` 覆盖小刘海实际窗口尺寸、自动收起及快速反向动画。预览位于 `artifacts/cue-annotation-toolbar.png`、`artifacts/cue-annotation-colors.png` 和 `artifacts/cue-toolbar-collapsed.png`。
