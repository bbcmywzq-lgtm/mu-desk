# 错题收集模块实现边界

Parent SKU: `MU-DESK`  
Module ID: `mistake-collector`  
Gate: Product Definition — accepted by direct implementation instruction 2026-08-22

## Product role

错题收集是 MU Desk 内部按需模块，不建立独立产品、进程、托盘、开机启动项、版本或安装包。用户从 MU Desk 首页模块卡片进入独立窗口；关闭窗口后不保留额外后台工作。

## User and dominant task

- User: 想先把零散错题截图可靠收在一起、以后再整理的个人用户。
- Dominant task: 将一张或多张本地错题截图拖入或选入个人错题库，并浏览已经收集的截图。

## First-version content model

- 一道错题对应一组截图；截图可以分多次逐张追加。
- 分组保留创建/更新时间；每张截图保留截图副本、导入时间和原始文件名。
- 首版不要求用户填写标题、学科、标签、答案或备注；导入完成即可形成记录。
- 数据只保存在本机，不进行网络上传。

## Visible content

- 一个明确的拖放区，同时提供“选择截图”按钮作为键盘和普通文件选择入口。
- 最近更新的错题分组，默认按更新时间从新到旧排列。
- 每组显示首图缩略图和截图数量；当前组显示全部截图。
- 空状态说明如何添加第一张截图；导入失败显示真实原因。

## Actions

- 拖入一张或多张 PNG、JPG/JPEG 或 BMP 截图。
- 通过文件选择器加入一张或多张截图。
- 打开一张截图查看原图。
- 新建一个空分组；没有分组时直接拖图会自动建立第一组。
- 从当前组移除截图或删除整组；删除前明确确认，并只移除模块保存的截图副本。

## States

- Empty: 还没有错题截图。
- Drag over: 明确提示可放下的图片数量或不支持的文件。
- Importing: 显示正在保存，避免重复操作。
- Populated: 显示按时间排列的截图记录。
- Import success: 显示实际成功数量；部分失败时同时列出失败数量和原因。
- Error: 文件读取、格式、磁盘或元数据保存失败保持可见，不伪装成成功。
- Delete confirmation / success / failure: 删除范围和结果清晰可见。

## Explicit exclusions

- OCR、题目文字识别、公式识别或自动裁边。
- 学科、标签、搜索、筛选、难度、答案、解析、批注和复习计划。
- 剪贴板监听、自动截屏或后台监视文件夹。
- 云同步、账号、分享、协作、导入 PDF 或相机拍照。
- 批量编辑、导出、回收站和永久存档策略。
- 独立用户入口、品牌、托盘、启动项、后台进程或安装包。

## Preservation requirements

- 不改变四向轮盘、动态拾取、光标画廊、桌面整理及其现有数据和行为。
- MU Desk 继续拥有唯一的普通用户入口、托盘、开机启动、设置、版本和发布包。
- 导入前不修改原始截图；首版删除只处理模块自己的记录和保存副本，不删除原始文件。
- 真实存储或读取错误必须可见；不得用演示数据替代失败。

## Gate A acceptance scope

用户在 2026-08-22 修正为“一道错题是一组截图，可能一张张加进去”，并明确要求停止定义、直接实现。实现继承 MU Desk 的 `light-outlined` 管理界面，数据位于 `%LocalAppData%\MU Desk\mistake-collector`。
