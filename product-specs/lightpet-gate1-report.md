# LightPet Gate 1 验收报告

> 历史阶段记录：本文保留 Gate 1 当时状态，不代表当前交付。最终结论以 `lightpet-acceptance-report.md` 和根目录 `LIGHTPET_README.md` 为准。

日期：2026-08-22

结论：代码与性能基线通过，等待用户完成实际动画手感确认。

## 已实现

- 新建独立 `LightPet.slnx`，不依赖 VPet 工程。
- WPF 透明置顶窗口。
- 原生 Windows 通知区图标，不加载 WinForms。
- 单实例、明确退出、位置保存、点击穿透。
- 数据型角色包和路径穿越防护。
- 固定 1000×1000 画布、固定锚点、不等帧时长。
- `Start / Loop / End / Single` 阶段模型。
- 只缓存当前动作，320px 解码，最多 6 张帧缓存。
- 待机、左右行走、摸头标杆动作。
- 头部点击和窗口拖动。
- 自主水平行走。

## 自动测试

构建：Release，0 警告，0 错误。

通过 6 项测试：

1. 加载合法角色包。
2. 拒绝目录穿越。
3. 拒绝缺少标杆动作。
4. 解析逐帧时长。
5. 拒绝错误 PNG 画布尺寸。
6. 命中头部点击区域。

重复启动测试：只保留 1 个 LightPet 进程。

## 性能测量

正常发行模式、自主活动开启、运行并完成动作切换后：

- 工作集：约 188.3MB。
- 私有内存：约 125.9MB。
- 20 秒 CPU 增量：0.766 秒。
- 单核心等效占用：约 3.83%。
- Windows 任务管理器归一化占用：约 0.12%（32 逻辑处理器）。
- 线程：约 66。
- 句柄：约 932。
- 程序保持响应。

Gate 1 红线：工作集小于 200MB、任务管理器口径空闲 CPU 小于 3%。两项均通过。

## 视觉检查

- QA 模式成功捕获真实透明窗口。
- 待机画面在固定画布中心显示，没有左右裁剪。
- 拖动操作成功改变窗口位置。
- 行走姿势在真实窗口中显示完整。
- 自动化点击工具无法稳定确认透明窗口上的摸头输入结果，因此摸头节奏和触发手感保留给用户实机确认。
