# CISP question-bank sources

- Interactive question text and diagrams: <https://github.com/npcola/CISP>, fetched 2026-08-22.
- Original five 100-question PDF sets and answer sheets: <https://gitcode.com/open-source-toolkit/b022c>, fetched 2026-08-22. The upstream README limits these materials to learning and non-commercial use.
- Additional reviewed question set: <https://github.com/hackctf55/cisp>, fetched 2026-08-24. Only questions with four complete options and one unambiguous highlighted answer were accepted from the scanned material.
- User-supplied 2026 review pack: eight Word documents covering CISE, CISO, and six CISP review sets, imported 2026-08-24. Questions were structurally validated and deduplicated against the existing bank and each other; relevant embedded diagrams were retained.
- Exam scope reference: China Information Security Evaluation Center, CISP (CISE/CISO) Body of Knowledge V2.3.

The merged offline edition contains 907 deduplicated questions. The user-supplied 2026 pack is also retained as eight isolated source sets containing 797 interactive questions in source order; those sets are never mixed during set practice. These are public study materials rather than official exam questions. They may contain outdated or incorrect answers. Source numbering and original files are retained where available for review.
